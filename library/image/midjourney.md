# Midjourney

Comma-separated descriptor strings, not instructions. Subject first, style late, parameters last.
Descriptor order follows [`../../references/tool-routing.md`](../../references/tool-routing.md) §Image:
`subject, action, setting, composition, lighting, style/medium, technical params` → `--ar --style --stylize --no`.

**On the Georgian block.** Midjourney does not handle Georgian input reliably, so the `**KA**` block here
is a *working version*: the same descriptor list in Georgian, so you can compose, edit and argue about the
shot in your own language — then, after the `---` line, the English string you actually paste.

ქართული ბლოკი სამუშაო ვერსიაა — Midjourney-ში ჩასასმელად გამოიყენე ბოლოს მოცემული ინგლისური სტრიქონი.
The Georgian block is the working draft — paste the English string that follows the `---` line.
